> **Note:** *TheEngine* is a working title for a custom lightweight, modular C++ game engine currently under active development.


## Minimum Requirements

* **Vulkan:** Version 1.3 support required
* **Operating Systems:** 
  * **Windows**
  * **Linux**
  * **Android** (Minimum API level 26 and Vulkan 1.3 support)
* **Build System:** CMake 3.17
* **Compiler:** C++ 20 compliant compiler
